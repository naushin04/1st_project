# 🎓 MBSTU Campus Navigation System

## 📌 About the Project

The MBSTU Campus Navigation System is a C++ console-based project designed to help users find routes between different locations on the Mawlana Bhashani Science and Technology University (MBSTU) campus.

It uses Dijkstra's Algorithm to find the shortest route based on distance.

## ✨ Features

- 📍 Display all campus locations
- 🗺️ Find the shortest route between locations
- 📏 Calculate total distance and road distances
- 🛣️ Display known road connections
- 🏢 View academic buildings and departments
- 🔎 Find a department's building and floor

## 🧠 Algorithm

**Dijkstra's Shortest Path Algorithm**

This algorithm finds the shortest path between locations in a weighted graph with non-negative edge weights.

## 🛠️ Technologies Used

- C++
- Graphs and Arrays
- Structures and Functions
- Dijkstra's Algorithm

## ▶️ How to Run

Compile the source file using a C++ compiler:

```bash
g++ main.cpp -o campus
```

Run on Windows:

```bash
.\campus.exe
```

Run on Linux:

```bash
./campus
```

## 🎯 Project Objective

The goal of this project is to demonstrate how graph-based navigation and shortest-path algorithms can help users navigate between campus locations.
